# ART_MAP.md - карта картинок событий

Генерируется `python3 _tools/art_map.py` (темы подбора - `_tools/art_themes.py`). Колонка «Решение» заполняется вручную и сохраняется при перезапуске. Кандидаты: **наш** - спрайт из `interface/UKR_event_pictures.gfx`; **TFR** - готовое попадание по теме; **TFR\*** - совпадение по словам в имени (слабее, смотреть превью). Прежде чем ставить картинку, проверить её в игре: ни имена, ни этот файл не заменяют превью.

**Своя картинка (снимок из прессы и т. п.):** сохранить в `gfx/event_pictures/` под именем из колонки «Имя файла» (PNG, **500x250**, пропорция 2:1), дописать спрайт `GFX_UKR_<имя без UKR_ и .png>` в `interface/UKR_event_pictures.gfx` и поставить его в `picture =` события. **Статус** (вручную, сохраняется при перезапуске): `найдено` - снимок выбран; `обработано` - обрезан, фильтр общего стиля, лежит в `gfx/event_pictures/`; `в моде` - спрайт описан и стоит в событии. Если файл с таким именем уже лежит в `gfx/event_pictures/`, статус «в моде» ставится автоматически. Для скрытых и служебных событий имя файла `-` (картинка не нужна). Событие с временной картинкой из уже существующего спрайта помечается в коде строкой `# art: reuse` над `country_event` и попадает в таблицу (колонка «Сейчас» - `(временная, чужая)`); строка `# art: -` означает, что картинка не нужна (событие страны-ответчика), и в таблицу такое событие не попадает.

Событий с временной картинкой: **245** (из них спрайт не определён нигде: **3**; оригиналы TFR: 16; скрытые, картинка не видна: 2; временные из существующих спрайтов, `# art: reuse`: 41); в таблице: 245.
Заглушка `GFX_report_event_ukrainian_civil_war` не найдена ни в индексе TFR, ни у нас: возможно, ванильный спрайт [ПРОВЕРИТЬ в игре, нет ли пустой рамки]. «Нет спрайта!» - картинка точно нигде не определена, в игре будет пустая рамка.
