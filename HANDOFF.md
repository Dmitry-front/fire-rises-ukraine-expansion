## 3. Ключевые решения сессии (кратко; полностью — журнал `DESIGN.md`, раздел 16)

**Блок 1**
- 1 cost = 7 дней (автор сверил `defines`). Бюджет до выборов 29.10.2023 ≈ 200 единиц.
- Склонности в блоке 1 **полностью скрыты**, без строк в локализации. Как показывать в блоках 2–3 — решим позже.
- «Золотой век» — **фокус-приманка**: игрок его не получает, скандал обрывает его, дерево меняется на блок 2. Награда в описании «сладкая» (+200 политсилы, +10% стабильности). Единый дух с модулями — на паузе. Требования и вид дерева («бутылочное горлышко») — в долг, TD-15.
- Три необязательных фокуса склонностей ответвляются от политической цепочки.

**2023 год**
- Порядок: сдвиг поля (кризис неолиберализма из-за войны в США → консолидация евролевых → усиление правых) → выборы 29.10 → **союз с «Батькивщиной» без выбора** (коалиция TFR, половина политсилы партнёра) → «Золотой век» + слухи → **превентивный распад союза** → митинги → блок 2.
- Без «Золотого века» цепочка слухов стартует сама 15.11.2023.
- В TFR Тимошенко — `neoconservative` (семейство `conservative`): союз идеологически пёстрый.
- Мем «Яйца по 17 гривен» — утверждён.

**Блок 2**
- `ukraine.13` вызываем **сами 21.04.2024**; опция «Порошенко» скрыта для игрока (ИИ может выбрать).
- **Андрей Ермак называется по имени**; обвинения — только «по версии следствия/СМИ».
- Полный скандал — в блоке 2 (после победы, до инаугурации).
- Развилки: Донбасс и ветераны АТО (левые / правые), цифровизация или личная лояльность (технократы / вертикаль), антикоррупционные органы, ставка на опору.
- Тимошенко — отдельный кандидат (возможно, позже своя ветка).
- «Стадион 2.0» и «Армия. Мова. Віра. Досвід» — переработки мемов 2019, а не копии.

**Блок 3**
- **У каждой опоры своё окно решений** с уникальными механиками.
- Технократы переименованы: **«институционалисты-технократы (либералы)»**. Лицо пути — **премьер Юлия Свириденко**; **Фёдоров — министр** (цифра; с войной — оборона, ещё не сделано).
- Фонд с США заменён **фондом ЕС (Ukraine Facility)** — в США гражданская война.
- **Левые (сессия 3):** левый премьер не нужен; лицо — министр **Виталий Дудин** («Соціальний рух»). Двоевластие — **баланс сил HOI4** (как `SOV_LDPR_balance` у ЛДПР). Национализация — **с названиями** (Ахметов, «Приват», Фирташ, телеканалы). Кроме трёх мини-путей — **четыре левые группы** (профсоюзы, социалисты, анархисты, радикальные коммунисты), их сила открывает мини-пути. **Тип экономики TFR меняется** по итогу реформ: welfare / кооперативная / плановая.
