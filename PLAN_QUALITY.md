## В. Карточки задач

### К1. Единая проверка одной командой (статус: не начато)

**Зачем.** Сейчас «чисто или нет» решает человек, сравнивая вывод с текстом в `CLAUDE.md`. Нужна команда с ответом «новых сообщений: 0» и ненулевым кодом возврата при ошибке.

**Можно менять:** `_tools/` (новые и существующие файлы), `.gitignore`, `CLAUDE.md` (только разделы «Проверки перед коммитом», «Известный шум аудита», «Ловушки окружения»).

**Шаги.**
1. `.gitignore`: добавить `__pycache__/` и `*.pyc`.
2. `_tools/audit.py`: не менять логику существующих проверок. Добавить:
   - сбор всех сообщений в список (каждое сообщение - одна стабильная строка без номеров строк файлов, чтобы она не менялась от посторонних правок);
   - файл `_tools/audit_baseline.txt` - известный шум, по одной строке на сообщение, с комментарием `#` о причине (перенести причины из `CLAUDE.md`, «Известный шум аудита»);
   - режим по умолчанию: печатать только сообщения, которых нет в baseline, и итог `новых сообщений: N; известный шум: M (совпадает | исчезло K)`; код возврата 1, если N > 0;
   - флаг `--full` - прежний полный вывод; флаг `--update-baseline` - переписать baseline (использовать только осознанно, с записью в журнал).
3. Новые проверки в `audit.py` (каждая - отдельный раздел вывода):
   - **Локализация наших ключей:** множества ключей с префиксами `UKR_`, `ukraine`, `ukr_` в RU и EN равны; в значениях нет символов U+2014, U+2013, U+2026; нет пустых значений (сейчас два: `ukraine.12.d`, `ukraine.14.d` - внести в baseline со ссылкой на К4);
   - **Объекты без текста:** каждый `id` фокуса во всех `common/national_focus/*.txt` (включая `shared_focus`), каждая идея `UKR_*` из `common/ideas/`, каждое решение `UKR_*` из `common/decisions/` имеют ключ и `_desc` в RU. Учесть: у идей-министров текст берётся из `name = ...`; `id` самого дерева (`UKR_block2`, `UKR_block3_*`) - не фокус; идеям `_desc` не обязателен;
   - **Флаги:** `has_country_flag` / `has_global_flag` на `UKR_*`, который нигде не ставится (`set_country_flag`, `set_global_flag`, обе формы записи: `= X` и `= { flag = X ... }`) - это ошибка; «ставится, но не читается» - только счётчик в сводке, не ошибка;
   - **Scripted effects и triggers:** вызов `UKR_*_... = yes` без определения - ошибка; определённый и нигде не вызванный (искать также в `interface/*.gui`, `common/scripted_guis/`, `common/scripted_localisation/`) - предупреждение;
   - **Фокусы:** `cost` вне 3-7 разрешён только из списка исключений в начале скрипта (`UKR_golden_age`, `UKR_w_war_comes_home`, `UKR_w_martial_law`, фокус блока 2 с cost 1, фокус блока 1 с cost 1 - имена взять из кода); `mutually_exclusive` симметричны; `prerequisite` указывает на существующий фокус того же дерева или общий;
   - **Отступы:** строки наших файлов `UKR_*.txt`, начинающиеся с 4 пробелов, - только счётчик по файлам.
4. Новый `_tools/check.py` - единая точка входа: запускает по очереди `audit.py`; все генераторы в режиме проверки; печатает одну итоговую строку `CHECK: OK` или `CHECK: FAIL (что именно)`; код возврата 0 или 1.
   - Режим проверки генераторов: если у генератора нет `--check`, сравнивающего результат с файлами на диске без записи, **добавить его** (собрать вывод в память, сравнить с файлом, вывести имена расходящихся файлов). У `gen_allies.py` уже есть `--check`, но он проверяет только данные: добавить сравнение с диском под отдельным флагом `--diff`, старое поведение не ломать.
5. В шапке каждого сгенерированного файла должна быть строка-комментарий «ГЕНЕРИРУЕТСЯ `_tools/...`, вручную не править». Где её нет - добавить **в генератор** (не в файл) и пересобрать; убедиться, что `git diff` показывает только эту строку. Это единственное разрешённое изменение игровых файлов в К1.
6. `CLAUDE.md`: в «Старт сессии» (шаг 3), «Проверки перед коммитом» и «Конец сессии» заменить `python3 _tools/audit.py` на `python3 _tools/check.py`; раздел «Известный шум аудита» сократить до трёх строк со ссылкой на `_tools/audit_baseline.txt`; из «Ловушек» убрать пункт «audit.py не видит новые деревья», если шаг 3 его закрыл.

**Критерий готовности.** `python3 _tools/check.py` печатает `CHECK: OK`, код возврата 0. Намеренная поломка ловится: (а) удалить один ключ из EN-файла - FAIL; (б) дописать пробел в сгенерированный файл - FAIL; (в) добавить `has_country_flag = UKR_zzz_test` - FAIL. После каждой пробы `git checkout -- <файл>`. Результаты трёх проб записать в журнал.
