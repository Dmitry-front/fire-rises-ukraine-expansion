## 1. Решения автора (вводные)

1. Решения **общие для всех мини-путей**, не привязаны к ветке.
2. Приоритет: **экономические, потом социальные, потом военные**. Главное - качество, раскрытие и взаимосвязь, а не число.
3. **Повторяемые решения двигают баланс к определённой ветке** и усиливают её национальный фокус. Игрок «прожимает» кооперативы: растут промышленное и общественное развитие, нужны политсила и немного денег. Это стимулирует переход экономики. **При смене формации не должно быть негатива, наоборот - временный бафф.**
4. **Левые силы требуют улучшения законов**, главное - условий труда. В TFR для этого есть национальный дух (раздел 3).
5. Живое описание окна со словами о ходе дел, **цветом для фракций**.

## 2. Что уже есть и что не хватает

Окно сейчас: 11 решений, почти все разовые. Четыре группы (профсоюзы, социалисты, анархисты, коммунисты) выходят из решений только как числа и дают доступ к развилке дерева (порог 30). Нет повторяемого «вложения» в курс, нет связи решений с выбором ветки и сменой экономики, нет требований групп. Нет и военных решений под ветки обороны (ветеранские кооперативы, тероборона).

Оставляем все 11 существующих. Меняем только `UKR_lc_workers_cooperative` (раздел 5, Э1) и добавляем новые.

## 3. Что делает TFR (референс)

Нашёл два образца, на которые опираемся:

- **`SOV_pro_labor_reforms_idea` -> `_1_idea` -> `_2_idea`** (`_referenceTFR_ideas_SOV.txt`, ~22825): лестница из трёх духов «Про-трудовые реформы». Ступени растут: `personal_value_factor` 0.1 -> 0.15 -> 0.2, `production_factory_max_efficiency_factor` 0.1 -> 0.15, `industrial_capacity_factory` 0.015 -> 0.05, `society_development_monthly` и `poverty_development_monthly` до 0.01. На последней ступени цена: `business_value_factor` -0.1. Поднимает ступени **повторное решение** `SOV_radicalize_the_party_progamme` через `swap_ideas` (`_referenceTFR_decisions_SOV.txt`, ~31870). Это прямой образец для нашей лестницы «Условия труда».
- **`SOV_upgrade_working_conditions_idea`** (~38380): дух с `personal_expense_factor` 0.2, `personal_value_factor` 0.1, `stability_weekly` 0.001, `society_development_monthly` 0.01. В `on_remove` он **превращается в постоянный прирост**: разово `society_development` +0.15 или в более сильный дух (`..._prosperity_idea`, `..._opportunity_idea`). Образец для «переходного баффа»: временный дух заканчивается и оставляет постоянный след.
- Имена `SOV_*` мы не используем (страновые). Делаем свои `UKR_*` по тем же ключам и масштабу.
- **Законы** (`TFR_CATALOG.md`, раздел 1) меняются как идеи в слотах. Нужные нам: `safety_laws` (`medium_safety` по умолчанию -> `high_safety` -> `higher_safety`: `stability_factor` 0.05 / 0.075, `production_factory_efficiency_gain_factor` до 0.1, но `industrial_capacity_factory` -0.025 / -0.05), `welfare_laws` (Украина стартует с `low_welfare`; `medium_welfare` -> `high_welfare` -> `higher_welfare`), `tax_laws` (`high_taxes`, `higher_taxes`), `education_laws` (`high_education`, `higher_education`), `police_laws` (`low_police`, `lower_police`), `trade_laws` (`medium_trade`, `low_trade`). Цена смены закона в TFR - 100 политсилы; у `lower_trade` условие `has_war=yes`.
- **Что неизвестно [ПРОВЕРИТЬ]:** налагает ли сам `change_economy_type_*` в TFR временный штраф (определение эффекта в репозитории не лежит). Поэтому под «нет негатива при смене формации» я понимаю **наши** штрафы и события (раздел 6) и добавляю бафф сверху. Если в игре окажется, что TFR сама бьёт при смене, поправим числа баффа.

## 4. Архитектура: как всё связано

```
повторяемые «курсовые» решения  ->  счётчик группы (Профсоюзы/Социалисты/Анархисты/Коммунисты)
                                 ->  «готовность перехода» ветки (0-100): социал-демократия, самоуправление, плановая
                                 ->  развитие, деньги, мелкие бонусы за каждое нажатие

счётчик группы >= 30             ->  открывает фокус развилки (уже есть)
готовность перехода              ->  усиливает награду фокуса развилки (+ влияет на экономику после)
фокус типа экономики (tp)        ->  «Переходный подъём»: временный бафф по готовности
                                     по окончании -> постоянный прирост (как SOV_upgrade_working_conditions_idea)
                                     + мягче наши штрафы пути (бегство капитала, европейское влияние, событие 504/510)

требования групп (миссии)        ->  улучшение законов, лестница духа «Условия труда»
                                     выполнил -> группа довольна, дух растёт; проигнорировал -> группа теряет, малый штраф

шкала «Рада <-> Банковая»        ->  каждая ветка двигает свою сторону, но в готовности перехода есть «страховка»
```

**Три «курса»** (общие решения, но каждое *тянет* к своей ветке):

| Курс | Группы | Ветка | Фокус типа экономики |
|---|---|---|---|
| **Социальный диалог** | профсоюзы, социалисты | социал-демократия | `UKR_l_welfare_economy` (`welfare_capitalism`) |
| **Самоуправление** | анархисты (+ профсоюзы) | самоуправление | `UKR_l_cooperative_economy` (`worker_controlled`) |
| **Госплан** | коммунисты | ортодоксальные | `UKR_l_gosplan` (`planned_economy`) |

Новые скрытые переменные: `UKR_lc_course_social`, `UKR_lc_course_self`, `UKR_lc_course_state` (0-100, «готовность перехода»). Видимых цифр не добавляем: слова и цвет в описании окна (раздел 7).

Игрок **не обязан** тянуть один курс: можно качать все три, но готовность каждого растёт медленно (убывающая отдача, раздел 8), и разворот на 180 градусов дороже. Это держит развилку спорной.

## 6. Механики подробно

### 6.1. «Готовность перехода» (курсовые переменные)

- Три скрытые переменные 0-100: `UKR_lc_course_social`, `UKR_lc_course_self`, `UKR_lc_course_state`.
- Каждое курсовое решение добавляет к ним 4-8 очков; **убывающая отдача**: после 60 очков прирост делится на 2, после 80 - на 3 (простая формула `add * (100 - course) / 100`, с минимумом 1).
- **Усиление фокусов развилки.** Награда фокусов `UKR_l_social_democracy`, `UKR_l_self_management`, `UKR_l_orthodox_left` получает добавку по готовности соответствующего курса: за каждые 20 очков +1% к популярности своей партии (максимум +5%) и +0.01 политсилы в неделю на 180 дн (дух «Школа курса» [ПРЕДЛОЖЕНО]).
- Развилка остаётся спорной: у каждого курса свой набор нажатий, и «чужой» курс при выборе ветки обнуляется на 50% (мягкая цена за разворот).

### 6.2. «Переходный подъём» (бафф вместо негатива)

Срабатывает в награде фокусов `UKR_l_welfare_economy`, `UKR_l_cooperative_economy`, `UKR_l_gosplan` (вместе со сменой типа экономики):

1. Берём готовность своего курса (`r`, 0-100).
2. Выдаём временный дух `UKR_lc_transition_boost` на 240 дней, его сила - динамический модификатор `UKR_lc_transition_dynamic` (схема как у духов сезона 2023): `industrial_capacity_factory` +`r*0.0006` (до 0.06), `production_factory_efficiency_gain_factor` +`r*0.0005`, `stability_weekly` +`r*0.00001`, `society_development_monthly` +`r*0.00012`. Не ниже минимального уровня при `r` < 20, чтобы награда за фокус всегда чувствовалась.
3. `on_remove`: постоянный прирост по образцу `SOV_upgrade_working_conditions_idea` - `society_development` и `poverty_development` +0.03...+0.1 (по `r`), для самоуправления - ещё `industrial_development`.
4. **Снятие наших штрафов:** при `r` >= 50 снимается `UKR_capital_flight` (если ещё стоит), отменяется штраф стабильности -0.03 у фокуса `UKR_l_gosplan`, а на `European_Influence` / `Russian_Influence` в фокусе развилки действует множитель 0.5 (при `r` >= 80 штрафа нет).
5. Это и есть «при смене формации нет негатива, а временный бафф».

Дух растёт только по решению (как `SOV_radicalize_the_party_progamme`), законы `safety_laws` / `welfare_laws` подтягиваются отдельными решениями (5.2). Иконки: чужие/временные, список в `CLAUDE.md`.

### 6.4. Требования групп (миссии)

- Раз в месяц (`on_monthly`, отдельный файл on_actions, как у олигархов) проверяется: если у группы счётчик >= 30, у неё нет активного требования и есть неисполненный закон из её списка - создаётся **требование**.
- Реализация: миссия `UKR_lc_demand_<группа>` в окне, срок 120 дней (`days_mission_timeout`), в тексте названа группа (цветом), закон и срок. Не больше **одного активного требования на группу** и **двух всего**.
- Исполнение: закон принимается решением `UKR_lc_law_*` (скидка) либо игроком вручную в окне законов; миссия закрывается по условию (`has_idea = high_safety`).
- Награда: группа +5, `UKR_left_lean` +1, стабильность +0.01, `UKR_labour_conditions_*` растёт на ступень (для профсоюзов).
- Игнор: группа -5, стабильность -0.02, затем событие забастовки (мелкое, через `ukraine_politics` 55x, ID выберу при написании) - **но без каскада**, чтобы не стать «ловушкой».

Какие требования у кого:

| Группа | Требования |
|---|---|
| Профсоюзы (оранжевый) | `high_safety`, `higher_safety`, `medium_welfare`, повышение МРОТ (событие/решение трудовой инспекции) |
| Социалисты (красный) | `high_taxes`, `high_education`, `high_welfare` |
| Анархисты (чёрный/серый) | `low_police`, самоуправление предприятий (счётчик кооперативов >= 3) |
| Коммунисты (тёмно-красный) | `medium_trade`, национализация (счётчик национализаций >= 3) |

### 6.5. Шкала «Рада <-> Банковая»

Баланс остаётся центральной механикой двоевластия. Курсы её слегка двигают (социальный диалог - к центру/Раде, самоуправление - к Раде, Госплан - к Банковой), но **два новых повторяемых решения** (5.4) дают игроку инструмент держать баланс, чтобы края 508/509 были выбором, а не случайностью.

## 7. Описание окна: слова и цвет

Основа - `UKR_social_contract_desc` + `defined_text` (как `UKR_OL_TREND_*` у олигархов). Предлагаемые блоки:

1. **Вступление** (как сейчас, чуть короче).
2. **Двоевластие:** `[UKR_LC_BALANCE_WORD]` - словесная оценка (Рада ведёт / рабочий компромисс / Банковая давит) по значению шкалы.
3. **Левые группы цветом** (цифры + слова по уровням: слабы / крепнут / сильны / ведут):

| Группа | Цвет текста | Слова по уровню |
|---|---|---|
| Профсоюзы | §O оранжевый | «разрозненны» / «держат отрасли» / «ведут переговоры» |
| Социалисты | §R красный | «на кухнях» / «в Раде» / «в правительстве» |
| Анархисты | §g серый | «на окраинах» / «в кооперативах» / «в каждом цехе» |
| Коммунисты | §p/§C [ПРОВЕРИТЬ палитру] | «на пикете» / «в профкомах» / «в приёмной» |

   Цвета в игре проверяем (в нашей локализации уже встречаются §Y §R §G §H §W §C §L §p §t §O §g). Если цвет не читается, меняем одну строку в локализации.
4. **Курсы:** `[UKR_LC_COURSE_WORD]` - словесно, какая ветка сильнее («курс на социальный диалог набирает ход», «кооперативная сеть крепнет», «план пока на бумаге»). Без цифр готовности.
5. **Требования:** если активны - `[UKR_LC_DEMANDS]` строкой с названием группы и закона.
6. **Условия труда:** уровень духа словами.

Отдельные цифры показываем только там, где игрок ими пользуется (счётчики групп уже печатаются).

## 8. Баланс и ИИ

- **Повторы:** каждое курсовое решение дороже на 5% за каждое применение внутри года (счётчик сбрасывается раз в год) [ПРЕДЛОЖЕНО]; плюс убывающая отдача по готовности (6.1).
- **Деньги:** суммы малые (0.3-1.5 млрд); пополнение - `UKR_lc_wealth_levy` (+3.0) и трудовая инспекция (+0.8), чтобы игрок не упёрся в ноль.
- **ИИ:** `ai_will_do` с весом: социальные и кооперативные - 10-15, Госплан - 4 (как ортодоксальная развилка - ловушка), законы по требованиям - 20 при активном требовании, шкала - 3-5. ИИ-Украина должна доходить до «Республики труда».
- **Стиль:** тексты 4-6 предложений в два абзаца, сухой тон, юмор мягкий, без длинных тире (`CLAUDE.md`).
