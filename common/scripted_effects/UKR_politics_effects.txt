# Распад союза (расчёт в immediate события 124): падает только «Слуга народа», освободившиеся проценты расходятся по остальным партиям.
# Потеря: база 10; −3, если ведущая склонность ≥ 50; ∓2 за каждый честный/нечестный ответ (UKR_honesty_2023). Пределы 5–15.
UKR_rada_union_collapse_calc = {
	set_variable = { UKR_sn_loss = 10 }
	if = {
		limit = {
			OR = {
				check_variable = { UKR_digital_lean > 49 }
				check_variable = { UKR_left_lean > 49 }
				check_variable = { UKR_authoritarian_lean > 49 }
				check_variable = { UKR_nationalist_lean > 49 }
			}
		}
		add_to_variable = { UKR_sn_loss = -3 }
	}
	set_temp_variable = { UKR_honesty_x2 = UKR_honesty_2023 }
	multiply_temp_variable = { UKR_honesty_x2 = 2 }
	subtract_from_variable = { UKR_sn_loss = UKR_honesty_x2 }
	clamp_variable = { var = UKR_sn_loss min = 5 max = 15 }
	round_variable = UKR_sn_loss
}

# Ставка на опору: штраф за разворот на 180° (DESIGN.md, 6.3).
# Перед вызовом: set_temp_variable = { UKR_pillar_lean_tmp = <склонность выбранной опоры> }
UKR_apply_pillar_mismatch = {
	if = {
		limit = { check_variable = { UKR_pillar_lean_tmp > 74 } }
		add_timed_idea = { idea = UKR_pillar_organic days = 365 }
	}
	else_if = {
		limit = { check_variable = { UKR_pillar_lean_tmp > 49 } }
		add_political_power = 25
	}
	else_if = {
		limit = { check_variable = { UKR_pillar_lean_tmp > 24 } }
		add_timed_idea = { idea = UKR_pillar_mismatch_minor days = 120 }
	}
	else = {
		add_stability = -0.05
		add_political_power = -50
		add_timed_idea = { idea = UKR_pillar_mismatch days = 180 }
	}
}
